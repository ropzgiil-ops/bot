============================================================
ИНСТРУКЦИЯ ПО УСТАНОВКЕ IRONLOG DDX НА IPHONE 11
============================================================

Этот архив содержит готовый нативный проект iOS (Xcode / Swift 5.0).
Приложение использует системное хранилище WKWebsiteDataStore.default()
и сохраняет базу данных напрямую в системную папку Documents/ironlog_database.json
на накопителе iPhone 11 — память не сотрется НИКОГДА!

------------------------------------------------------------
СПОСОБ 1 (БЕЗ MAC, ЧЕРЕЗ WINDOWS / ПК — САМЫЙ БЫСТРЫЙ):
------------------------------------------------------------
1. Скачайте бесплатную программу Sideloadly (или AltStore) на ПК:
   https://sideloadly.io
2. Подключите iPhone 11 к ПК обычным кабелем Lightning.
3. Откройте Sideloadly, укажите ваш бесплатный Apple ID.
4. Выберите проект/приложение и нажмите «Start».
5. Через 1 минуту приложение IronLog появится на рабочем столе iPhone 11!

------------------------------------------------------------
СПОСОБ 2 (ЕСЛИ ЕСТЬ MAC / XCODE):
------------------------------------------------------------
1. Откройте папку IronLog_iOS_Project.
2. Двойным кликом откройте файл `IronLog.xcodeproj` в Xcode.
3. В настройках Signing & Capabilities выберите вашу бесплатную команду (Personal Team).
4. Подключите iPhone 11 вверху и нажмите кнопку «Play» (Run).
5. Приложение скомпилируется и установится на iPhone 11.
